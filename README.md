# ایرپلاس — سایت پرواز (Next.js)

سایت تک‌صفحه‌ای که با اسکرول، دوربین را روی مسیر پروازی از میان ابرها می‌برد، همراه با پنل مدیریت برای تغییر همه‌ی محتوا.

## اجرا

```bash
npm install
cp .env.example .env.local     # رمز و کلید ادمین را عوض کنید
npm run dev                    # http://localhost:3000  و  /admin
```

نسخه‌ی نهایی: `npm run build && npm start`

## پنل مدیریت (`/admin`)

- **بخش‌های داینامیک**: هر تعداد بخش (۱ تا ۱۲) اضافه، حذف، تکثیر و جابه‌جا کنید. انواع بخش: شروع، محتوا، مراحل، آمار، نظر مشتریان، فرود و فرم. طول مسیر پرواز، ابرها و اشیای سه‌بعدی خودکار با تعداد و ترتیب بخش‌ها تنظیم می‌شود.
- بخش «محتوا» می‌تواند شیء سه‌بعدی داشته باشد: بلیت‌های شناور یا ستون‌های گزارش.
- بخش «مراحل»: هر مرحله یک ابر غلیظ روی مسیر است و هنگام عبور هواپیما از آن، مرحله روشن می‌شود.
- بخش «فرود» را آخر بگذارید (باند فرود همیشه انتهای مسیر است).
- تب **درخواست‌ها**: درخواست‌های دموی ثبت‌شده از فرم سایت، با حذف و خروجی CSV.
- برند، فوتر (ستون‌ها، شبکه‌های اجتماعی، لینک‌های حقوقی) و اطلاعات تماس هم قابل ویرایش‌اند.

## هواپیما و رنگ سازمانی

- هواپیما مدل واقعی **Airbus A320-200** است (`public/models/a320.glb`، حدود ۲٫۲ مگابایت، ۱۱۵ هزار مثلث). مدل اصلی ۴۷۴ هزار مثلث و ۱۵ مگابایت بود و برای وب ساده‌سازی شد.
- لیوری با رنگ سازمانی: دم و شارکلت‌ها بنفش `#6f10d3`، نوار بدنه و نوار دم طلایی `#e4b817`. رنگ‌ها در خود فایل GLB ذخیره شده‌اند.
- همین دو رنگ در کل سایت (دکمه‌ها، پنل‌ها، لودر، فوتر، آسمان غروب و شب، بلیت‌ها و ستون‌های سه‌بعدی) استفاده شده است.
- اگر فایل مدل لود نشود، یک هواپیمای ساده‌تر (ساخته‌شده با کد) جایگزین می‌شود.
- **مجوز مدل CC BY 4.0 است؛ ذکر نام سازنده الزامی است.** این ذکر در فوتر سایت آمده است، آن را حذف نکنید. متن مجوز: `public/models/a320-license.txt`.

## قابلیت‌های سایت

- هواپیما با **موس** هدایت می‌شود (فنر و دمپر، چرخش و شیب طبیعی، تلاطم هنگام عبور از ابر). در موبایل، حرکت آرام خودکار.
- ابرهای حجمی با شیدر اختصاصی؛ عبور از میان ابر با سفیدی، مه و لرزش ملایم دوربین.
- دنباله بخار موتورها، چراغ‌های چشمک‌زن هواپیما، آسمان با زاویه خورشید و رنگ‌های شفق تا شب.
- نام برند: انیمیشن لودر، درخشش نام در هدر و نوشته‌شدن نام در آسمان ابتدای پرواز.
- نشانگر موس انیمیشنی، ابزار پرواز (ارتفاع، سرعت، جهت)، صدای محیطی (WebAudio، پیش‌فرض خاموش)، پرواز خودکار، کلیدهای ↑ ↓ Home End، انتخاب کیفیت (خودکار/بالا/کم)، فرم درخواست دمو.
- `prefers-reduced-motion` رعایت می‌شود؛ بدون WebGL محتوا به‌صورت ساده نمایش داده می‌شود.

## نکته‌ی استقرار

محتوا (`data/content.json`) و درخواست‌ها (`data/leads.json`) روی دیسک نوشته می‌شوند. روی VPS/Docker (با volume) کار می‌کند، اما روی پلتفرم‌های serverless مثل Vercel دیسک فقط‌خواندنی است؛ در آن صورت توابع `readContent/writeContent` و `readLeads/writeLeads` را با یک پایگاه‌داده (SQLite/Postgres/Supabase) جایگزین کنید. جای دیگری از کد تغییر نمی‌کند.
